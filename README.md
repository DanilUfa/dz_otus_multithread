# ArraySumBenchmark

Домашнее задание «Многопоточный проект»: сумма элементов массива `int` тремя способами.

1. **Последовательно** — обычный цикл.
2. **Параллельно** — массив делится на части, каждая суммируется в отдельном потоке `Thread` (по числу логических процессоров).
3. **LINQ (PLINQ)** — `array.AsParallel().Sum(x => (long)x)`.
