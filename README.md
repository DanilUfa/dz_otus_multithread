# ArraySumBenchmark

Домашнее задание «Многопоточный проект»: сумма элементов массива `int` тремя способами.

1. **Последовательно** — обычный цикл.
2. **Параллельно** — массив делится на части, каждая суммируется в отдельном потоке `Thread` (по числу логических процессоров).
3. **LINQ (PLINQ)** — `array.AsParallel().Sum(x => (long)x)`.

## Запуск

```
dotnet run -c Release
```

## Окружение

| Параметр | Значение |
|---|---|
| ОС | Microsoft Windows 10.0.22631 (Windows 11) |
| Процессор | Intel(R) Core(TM) i5-12450H, 12 логических процессоров |
| Память | 15,7 ГБ |
| .NET | 10.0.12 (Release) |
| Потоков в варианте Thread | 12 |

## Результаты замеров (мс, минимум из 5)

| Размер массива | Последовательно | Thread | LINQ (PLINQ) |
|---:|---:|---:|---:|
| 100 000 | 0,067 | 1,701 | 0,436 |
| 1 000 000 | 0,606 | 1,462 | 2,871 |
| 10 000 000 | 5,858 | 3,348 | 16,775 |

Все три способа возвращают одинаковую сумму.

## Вывод

Параллельное суммирование на потоках выигрывает на больших массивах (10 млн элементов),
но на маленьких — накладные расходы на создание потоков больше самой операции.
